# 03 · 页面原型：七个骨架

> 先选骨架，再谈金色。骨架错了，再多的金边也像「游戏风模板」。
> 所有原型都来自「大世界 HUD / 档案 / 图鉴 / 对话 / 祈愿 / 地图」这六种信息状态；第七个是它们的移动端形变。

## 0. 通用页面壳

```
┌────────────────────────────────────────────────────────────┐
│ HUD 68px：品牌/菱形 · 导航胶囊 · 队伍头像 · 用户            │
├──────┬──────────────────────────────────────┬──────────────┤
│ 小地图│              主内容                    │  任务追踪     │
│ 104px│         minmax(0,1fr)                 │   260px      │
│      │                                      │              │
├──────┴──────────────────────────────────────┴──────────────┤
│ 底部动作栏：52px 圆形 ×4（可省略）                           │
└────────────────────────────────────────────────────────────┘
```

- **HUD**：高 66–72px；半透明纸面/星海底 + 1px 金线底边；固定或 sticky。
- **左栏**：小地图/地区索引，宽 96–120px；移动端隐藏。
- **右栏**：任务/快捷信息，宽 240–280px；移动端折叠到主内容之后。
- **内容宽**：1180–1440px；面板内边距 20–26px；页面左右 gutter 20–64px。
- **底栏**：动作/CTA 栏 52px 圆形按钮；不是每个页面都需要。

## 1. 大世界入口 / HUD Landing（夜幕）

**用在**：首页、版本页、活动页、产品主视觉、游戏官网首屏。**不用在**：长文、图鉴列表。

```
HUD
┌──────────────────────────────────────────────────────────┐
│ 小地图    [元素徽记 · 巨大标题 · 英文副标 · Lead]   任务追踪 │
│  圆环     [主按钮 启程] [次按钮 查看]                 3 条任务│
│          [底部动作栏 剑 弓 翼 囊]                         │
└──────────────────────────────────────────────────────────┘
羊皮纸/星海内容区：七元素卡 / 版本亮点 / 角色预告
```

| 元素 | 桌面 | 移动 | 备注 |
|---|---|---|---|
| 主标题 | 衬线 56–96px | 44–64px | 中英双层；英文小标字距 .24em |
| 元素徽记 | 直径 320–560px，opacity .06–.10 | 80vw | 作为背景，不是 logo |
| 小地图 | 104px 圆环 + 罗盘 | 隐藏 | 圆环 1px 金边 + 虚内环 |
| 任务追踪 | 260px 面板，3 条 | 移到主内容后 | 每条 2 行：任务名 + 类型 |
| 底部动作 | 52px 圆形 ×4 | 46px ×4，居中 | 圆形金边，hover 填元素色 |
| 主 CTA | 深墨底 + 金边 + 菱形前缀 | 同 | 最多 2 个 CTA |

**最容易崩**：把元素徽记做成真 logo（大面积高饱和）；标题用黑体而非衬线；HUD 覆盖主视觉文字。

## 2. 角色档案（白昼）

**用在**：角色详情、人物介绍、团队页、产品人物卡。**不用在**：列表页。

```
┌──────────────┬────────────────────────────────────┐
│ 拱形立绘框    │ 角色名（衬线） / 英文 / 元素/武器      │
│ 元素徽记      │ 属性 4 格 / 天赋 3 行 / 命之座环      │
│ 五星 / 等级   │ 金色分隔线贯穿                         │
└──────────────┴────────────────────────────────────┘
```

- 左侧卡：宽 300–420px，立绘框用拱形 `border-radius: 160px 160px 10px 10px`；星数与元素徽记压在框内。
- 右侧：顶部 tab（属性/天赋/命之座），下方 4 列属性格；天赋行 44px 圆形图标 + 名称/描述/等级。
- 命之座：132px 圆环 + 6 个菱形节点，激活节点元素色发光；不要做成 6 张卡片。
- 移动端：立绘上、信息下；属性 2×2；命之座环居中。
- **不搬官方立绘**：用自绘渐变/剪影/用户自有图片；本 skill 的 starter 用元素字 + 徽记代替。

**最容易崩**：立绘框用直角/切角（ZZZ 味）；属性格超过 4 个；命之座做成列表。

## 3. 图鉴 / 背包（白昼）

**用在**：物品/角色/武器/圣遗物图鉴、内容库、产品列表、作品集。**不用在**：单篇长文。

```
┌ 左分类 180px ┬ 顶部 tab 胶囊 ─────────────────────┐
│ 全部/武器/圣遗物│ 4 列物品卡（品质边框 + 星级）       │
│ 筛选：元素/品质 │ 卡：图 1:1 / 名 / 类型 / 星          │
└──────────────┴────────────────────────────────────┘
```

- 卡宽 180–280px；4 列（1440）/3 列（1024）/2 列（640）/1 列（480）。
- 品质边框：3 星蓝、4 星紫、5 星金；卡片底光用品质色 10–15%。
- 图区 1:1，内部用元素/物品符号；hover 上浮 3px + 金边。
- 顶部 tab 用胶囊 + 菱形激活标记；左侧分类可用文字 + 计数。
- 移动端：分类横向滚动，卡片 2 列。
- **最容易崩**：五颜六色的品质光；卡片没有星级；图区用游戏原图。

## 4. 任务 / 对话（白昼）

**用在**：任务详情、对话、剧情、FAQ、引导。**不用在**：列表页。

```
┌ 圆形头像 88px ┬ 说话人名（衬线，元素色）            │
│               │ 正文 14px / 1.9，最多 68ch          │
│               │ 选项：菱形前缀 ×2–3                  │
│               │ 主 CTA                                 │
└───────────────┴──────────────────────────────────────┘
```

- 对话框底色 `--gs-paper-grad`；1px 金边 + 内层淡金线 + 角饰。
- 选项是按钮：纸底 + 淡金边，hover 元素色边；菱形作为 bullet。
- 移动端：头像 64px，选项全宽。
- **最容易崩**：整段说明文（用户明确反感）；用「这是一个……」开头；选项超过 4 个。

## 5. 祈愿 / 星海（夜幕）

**用在**：抽卡/开箱/发布/活动揭晓/结果页。**不用在**：日常内容页。

```
星空底 + 金色星轨 + 元素徽记
┌────────────────────────────────────────────┐
│ 祈愿标题（衬线） / 概率/保底（等宽小字）      │
│ [祈愿 1 次] [祈愿 10 次]                     │
│ 结果卡：品质边框 + 光晕 + 星辉浮现             │
└────────────────────────────────────────────┘
```

- 底：`--gs-night-grad` + 星点 + 极淡噪点；元素光辉只做局部。
- 星轨/徽记：1px 金线圆环 + 虚线内环；缓慢旋转 60–80s（reduced motion 停）。
- 结果卡：5 星金边 + 金色光晕；出现时「星辉浮现」500–600ms（见 05）。
- 移动端：单列结果卡，按钮全宽。
- **最容易崩**：把祈愿做成紫蓝渐变抽奖转盘；大面积霓虹；动画超过 1s。

## 6. 地图 / 地区档案（白昼或夜幕）

**用在**：地区介绍、门店/项目地图、世界观地图、导航页。**不用在**：纯列表。

```
┌ 地区标题（衬线）+ 英文/编号 ────────────────┐
│ 地图画布（羊皮纸/星海）+ 菱形路标 + 地区标签  │
│ 右侧/底部：地点列表（图标 + 名称 + 距离）     │
└──────────────────────────────────────────────┘
```

- 地图用 CSS 渐变 + 自绘路径/等高线，不要直接截游戏地图。
- 路标：菱形 + 元素色；激活路标外圈发光。
- 地区标签：衬线中文 + 等宽英文；压在路径旁，不遮挡。
- 移动端：地图 16:10，下方列表；路标点击滚动到列表项。
- **最容易崩**：地图上放满图钉；用真实地图截图；没有层级。

## 7. 移动端 HUD（形变）

**用在**：以上原型的 390px 版本。**规则**：重排一次，不要只是缩小。

- HUD：60px；品牌 + 当前页 + 搜索/菜单；导航折叠到抽屉。
- 小地图：隐藏或缩成 44px 圆钮。
- 任务追踪：折叠为 1 行「当前任务」条，点击展开。
- 主标题：44–64px；两行以内。
- 面板：内边距 18–20px；圆角 14–16px；角饰 20px。
- 底部动作栏：46px 圆形 ×4，safe-area 内边距。
- 图鉴：2 列；角色：单列；对话：头像 64px。
- 任何 390px 页面不得横向滚动；`clip-path`/角饰不能溢出。

## 8. 三档断点

| 断点 | 内容宽 | 列数 | HUD | 小地图/任务 |
|---|---|---|---|---|
| 1440+ | 1180–1440 | 4 | 72px 全导航 | 104 / 260 |
| 1024 | 100% - 2×40 | 3 | 68px 全导航 | 96 / 240 |
| 760 | 100% - 2×20 | 2 | 60px 折叠 | 隐藏 / 折叠 |
| 390 | 100% - 2×16 | 1–2 | 60px | 隐藏 |

三档各验两件事：**金边是否被裁**、**拱形/圆环是否变形**。

## 9. 选型口诀

1. **大世界入口** = 星海 + 圆环 + HUD
2. **角色档案** = 拱形立绘 + 4 格属性 + 命之座
3. **图鉴背包** = 左分类 + 胶囊 tab + 品质卡
4. **任务对话** = 圆头像 + 纸框 + 菱形选项
5. **祈愿** = 星轨 + 金边结果卡
6. **地图** = 纸/星海画布 + 菱形路标
7. **移动端** = 全部重排一次
