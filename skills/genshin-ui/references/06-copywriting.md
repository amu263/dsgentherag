# 06 · 文案与语气

> 目标：让界面像档案里本来就有的字，而不是运营硬塞的说明。
> 用户明确反感「莫名其妙的说明性文字」和「冗余文字」；这条优先级高于任何文案公式。

## 0. 三条硬规则

1. **一屏一句话**：主视觉只保留「标题 + 一句短副标 + 必要操作」；不要在主视觉里解释这个页面是干什么的。
2. **标签优先于句子**：能用「风 / ANEMO」「Lv.90」「祈愿」说清的，不要写成「这里是风元素的信息」。
3. **不写元叙述**：禁止「这是一个……」「本页面用于……」「你可以在这里……」「欢迎来到……」这类把界面当说明书的句子。

## 1. 语气

- 世界内的档案口吻：短、稳、留白，像写给旅行者的便笺。
- 称呼用「旅行者」，不确定时用第二人称「你」；避免「亲」「宝子」「家人们」。
- 动词优先：启程、收录、祈愿、调阅、点亮、返回。
- 不堆形容词；不写「极致」「震撼」「超绝」这类营销词。
- 中文为主，英文只做小标/编号，不做整段英文。

## 2. 标题公式（中文 4–10 字）

| 公式 | 例句（自造） | 英文副标 |
|---|---|---|
| 意象 + 动作 | 风起之时 / 星海之约 | WHEN THE WIND RISES / ASTRAL INVITATION |
| 地点 + 档案 | 蒙德旧档 / 璃月风物 | MONDSTADT FILES / LIYUE RECORDS |
| 对仗 4+4 | 风过群山 星落长夜 | OVER THE RIDGES |
| 角色 + 称谓 | 风之旅人 / 岩之守望 | THE WANDERER / THE WARDEN |
| 版本宣言 | 星海篇 · 启程 | VERSION 1.0 / ASTRAL |

- 标题不加问号/感叹号；不用「你绝对想不到」。
- 英文副标全大写、2–4 词、名词堆叠、删冠词；字距 0.18–0.26em。
- 英文不是中文的逐字翻译，取意象（风起之时 → WHEN THE WIND RISES）。

## 3. 标签/按钮的固定句式

| 位置 | 文案 | 上限 |
|---|---|---|
| 主 CTA | 启程 / 祈愿 / 收录 / 调阅 | 2–4 字 |
| 次级 CTA | 查看七元素 / 返回档案 | 6 字 |
| 导航 | 旅程 / 角色 / 祈愿 / 地图 | 2–4 字 |
| 版本角标 | VERSION 1.0 | 10 字符 |
| 品质 | ★★★★★ / 五星 | — |
| 任务类型 | MAIN QUEST / SIDE QUEST / DAILY | — |
| 元素 | 风 / 岩 / 雷 / 草 / 水 / 火 / 冰 | 1 字 |
| 空状态 | 这里还没有收录。 | 1 句 |

按钮不要写「点击这里」「了解更多」；用具体动作。

## 4. 微文案

- 卡片：名称 + 类型 + 星级；不写「这张卡是……」。描述最多 2 行（≤ 46 字）。
- 角色：名称 + 元素 + 武器 + 等级；背景故事放折叠/详情，不放在首屏。
- 数值：`Lv.90`、`14,280`、`+48`、`1/6`；数字用半角。
- 日期：档案用 `2026.11.20`；列表用 `2026-11-20`；不要混用。
- 单位/元素：`ANEMO / 风`，英文在前或后统一，不要一行里换顺序。
- 提示：只在出错/空状态出现；正常操作不要 Toast 解释「你刚刚点击了」。

## 5. 页面各区块的写法

| 区块 | 写什么 | 不写什么 |
|---|---|---|
| HUD | 品牌 + 导航 + 队伍/用户 | 站点介绍、slogan 堆叠 |
| Hero | 标题 + 英文副标 + 1 句 lead + 1–2 CTA | 功能清单、300 字介绍 |
| 档案面板 | 数值、天赋名、命之座 | 教程式解释 |
| 图鉴 | 名称 + 类型 + 星级 | 每张卡的营销文案 |
| 对话 | 说话人 + 1–2 句 + 2–3 选项 | 世界观百科 |
| 页脚 | 版权、版本、必要链接 | 大段免责声明（除非合规需要） |

## 6. 原神味 vs 不是

✅ 「风从蒙德吹来，穿过山川与旧城。」
✅ 「命之座 · 旅人」「点亮第一颗星辰。」
✅ 「这里还没有收录。」（空状态）
✅ 「VERSION 1.0 / ASTRAL INVITATION」

❌ 「这是一个以原神 UI 风格设计的角色档案页面，你可以在这里查看……」
❌ 「欢迎来到我们的网站，本站致力于为用户提供……」
❌ 「点击下方按钮即可开始您的探索之旅！」
❌ 大段照搬游戏台词/角色语音/官方文案

## 7. 版权与原创

- 不复制游戏内文本、角色台词、任务描述、官方文案；只蒸馏语气与句式。
- 专有名词（提瓦特、蒙德、璃月、命之座、祈愿）可以作为世界观词汇使用，但不要拼接成官方未发布的「新设定」。
- 英文副标、标题、例句自己写；不要用官方 slogan。
- 素材（立绘/图标/Logo/KV）一律不搬；用自绘 SVG/CSS 或用户自有素材。

## 8. 交付前文案自检

- [ ] 删掉所有「这是/本页/用于/你可以在这里」句式后，页面还完整吗？
- [ ] 主视觉是否只有标题 + 一句副标 + 必要操作？
- [ ] 每个按钮是否是具体动作，而不是「了解更多」？
- [ ] 卡片描述是否 ≤ 2 行？
- [ ] 英文小标是否全大写、2–4 词、无冠词？
- [ ] 是否有照搬游戏原文？有就重写。
