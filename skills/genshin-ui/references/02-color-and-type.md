# 02 · 颜色与字体

> 所有色值来自 `assets/genshin-tokens.css`。业务页面只写 `var(--gs-*)`；本文件是解释与选色，不是第二份色板。

## 2. 七元素（一屏只启用一个）

| 元素 | Token | 主色 | 浅色（暗底/徽记） | 深色（纸底小字） |
|---|---|---|---|---|
| 风 Anemo | `--gs-anemo` | `#6FC7AE` | `#A9E4D2` | `#2F7F6D` |
| 岩 Geo | `--gs-geo` | `#E3B45C` | `#F5D79C` | `#8F6424` |
| 雷 Electro | `--gs-electro` | `#B58BE8` | `#D8BCF7` | `#6F439F` |
| 草 Dendro | `--gs-dendro` | `#A3C94A` | `#CDE38A` | `#5D7A22` |
| 水 Hydro | `--gs-hydro` | `#59B7E6` | `#A5DDF5` | `#2478A8` |
| 火 Pyro | `--gs-pyro` | `#E97A55` | `#F7B49A` | `#A54126` |
| 冰 Cryo | `--gs-cryo` | `#8ED6E4` | `#C7EEF5` | `#3E8B9E` |

用法：
- 元素主色：徽记底、激活 tab、进度环、按钮 hover、焦点环。
- 元素浅色：暗底上的文字/描边；徽记外圈。
- 元素深色：纸底上的 12–16px 文字/图标；**不要**用主色在纸底写小字（对比度不够）。
- 元素色面积 ≤ 屏幕 15%；其余交给纸、墨、金。

品质色：3 星 `#6FA8D8`，4 星 `#A88CE0`，5 星 `#E0B45C`。品质色只用在边框、底光、星星，不用于正文。

## 3. 对比度与可读性

- 纸底正文：`--gs-ink-700`（#4A4F60）对 `--gs-ivory-0` 约 8:1；小字用 `--gs-ink-500` 约 5.5:1。
- 纸底元素小字：用 `*-deep`（如 `--gs-anemo-deep`），不用 `--gs-anemo`。
- 暗底正文：`--gs-night-100` 对 `--gs-night-900` 约 12:1；弱字 `--gs-night-300` 约 5:1，仅用于 12px 以下注释。
- 金色文字只用于标题、徽记、装饰；正文金色会显得「土豪」且对比度不稳。
- 不要把元素主色当按钮文字色放在纸底；按钮用深墨底 + 浅金字，或纸底 + 深墨字 + 金边。

## 4. 字体

### 三套字，各司其职

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 展示 Display | `Cinzel`, `Noto Serif SC`, `Source Han Serif SC`, `Songti SC`, serif | 大标题、章节名、角色名、英文副标 |
| UI | `HYWenHei 85W`, `HYWenHei`, `汉仪文黑`, `Noto Sans SC`, `PingFang SC`, `Microsoft YaHei`, sans | 导航、按钮、标签、正文、表格 |
| 数字/编号 | `Sora`, `Cascadia Code`, `JetBrains Mono`, monospace | 等级、伤害、编号、日期、英文小标 |

**先把字体事实说清**：游戏内真正的主字体是米哈游改制的 **HYWenHei-85W（汉仪文黑 85W）**，菜单、角色名、按钮、正文都用它；**游戏内标题不是衬线体**。Cinzel / 思源宋体是网页为了「典籍感」引入的展示层，属于二创转译，不是官方原样。两种模式二选一：

- **忠实模式**（更像游戏内）：标题也用粗黑（Noto Sans SC 900 / 思源黑体 Heavy），只保留英文小标与装饰线；适合角色档案、背包、任务。
- **叙事模式**（更像官方 KV）：首屏/活动页标题用衬线展示字，UI 仍用粗黑；适合祈愿、版本页、专题页。模板默认叙事模式，改回忠实模式只需把 `--gs-font-display` 指到 `--gs-font-ui`。

**字体授权**：HYWenHei / 汉仪文黑是商业字体，本 skill **不内嵌、不分发**；只把它写进 `font-family` 作为「本机已安装则使用」的回退。没有安装时用 Noto Sans SC / 思源黑体，风格仍然成立。Cinzel 是 OFL，可自托管；中文展示字用思源宋体（OFL）。

### 字阶（桌面 / 移动）

| Token | 桌面 | 移动 | 用途 |
|---|---|---|---|
| `--gs-fs-display` | 48–88 | 44–64 | 首页大标题 |
| `--gs-fs-3xl` | 44 | 36 | 章节标题 |
| `--gs-fs-2xl` | 34 | 30 | 面板标题 |
| `--gs-fs-xl` | 26 | 24 | 角色名/大数字 |
| `--gs-fs-lg` | 20 | 18 | 小标题 |
| `--gs-fs-md` | 16 | 16 | 重点正文 |
| `--gs-fs-body` | 14 | 14 | 正文 |
| `--gs-fs-sm` | 12 | 12 | 标签、次级信息 |
| `--gs-fs-xs` | 11 | 11 | 注释 |
| `--gs-fs-micro` | 10 | 10 | 英文小标、编号 |

排版规则：
- 中文大标题字距 `0.06–0.10em`，不要负字距（衬线会挤）。
- 英文小标全大写、字距 `0.18–0.26em`、10px 左右。
- 正文行高 1.8–1.9；面板内文字不要超过 70ch。
- 数字用 `font-variant-numeric: tabular-nums`（表格/数值）。
- 标题与正文之间用金色细线或 16–24px 空白分隔，不要只靠字号。

## 5. 间距、圆角、阴影

- 间距 4px 基线：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 / 80 / 96。
- 面板内边距 20–26px；卡片内边距 10–14px；HUD 高 68–72px。
- 圆角：小控件 6–10px；卡片 10–16px；面板 16–22px；胶囊 999px；立绘框用拱形 `160px 160px 10px 10px`。
- 阴影：大而软、低透明度；面板阴影 Y 偏移 20–30px、blur 50–70px、alpha ≤ .45。不要用硬投影。
- 金色边框：`border: 1px solid var(--gs-gold-500)` + 内层 `::before` 1px `var(--gs-line-soft)` + 四角角饰。暗底把金边换成 `--gs-gold-300`。

## 6. 质感配方

- **纸纤维**：`parchment-grain.svg` 叠在底色上，`opacity .10–.16`，`mix-blend-mode: multiply`；暗底用 `screen`、`.06–.10`。
- **星海**：`radial-gradient` 深蓝底 + 1px 金色星点（多个 `radial-gradient` 定位）+ 极淡噪点；不要用星空视频/大图。
- **元素辉光**：`radial-gradient(circle at 50% 45%, color-mix(in srgb, var(--gs-accent) 30%, transparent), transparent 68%)`，面积控制在徽记/卡片周围。
- **金箔**：`--gs-gold-grad` 只用于 1px 线、菱形、按钮边、少量标题渐变；不要给整块面板刷金。
- **内发光**：`box-shadow: inset 0 1px 0 color-mix(...)` 模拟纸面受光；暗底用极低透明度。

## 7. 图标与纹样（自绘，不搬游戏资产）

- 菱形：`clip-path: polygon(50% 0,100% 50%,50% 100%,0 50%)`，用于 tab 标记、列表符号、按钮前缀。
- 四芒星：`star.svg` 或两条交叉的渐变线，用于品质/评级。
- 元素徽记：`sigil.svg` 作为 mask，用 `background: var(--gs-accent)` 上色；不要直接贴游戏元素图标。
- 角饰：`gold-corner.svg` 四角旋转；线宽 1–1.2px，尺寸 22–28px。
- 命之座：圆形轨道 + 菱形节点 + 虚线内环；激活节点用元素色发光。
- 所有图标用 `currentColor` 或 mask 上色，保证跟随元素/主题切换。

## 8. 常见配色错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 七个元素全用上 | 像儿童色卡 | 只留一个，其他用墨金 |
| 纸底用亮元素色写 12px 字 | 看不清 | 改 `*-deep` 或深墨 |
| 暗底用深金 `#503C1B` | 糊成一团 | 用 `--gs-gold-300/100` |
| 大面积金色渐变背景 | 土豪金 | 金只做线/边/徽记 |
| 纯黑 `#000` 当夜幕底 | 死黑、无星海感 | 用 `--gs-night-950/900` 靛蓝 |
| 只改颜色不改字体/圆角 | 像换肤插件 | Display + UI + 金线 + 拱形一起改 |
