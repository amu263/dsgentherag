# 01 · 设计 DNA：提瓦特档案是什么味道

> 目标：让你做的页面像从提瓦特大陆的档案室里抽出来的一页，而不是「加了金色边框的 Bootstrap」。
> 不是画原神角色，也不是复刻游戏截图；是蒸馏它的材质、比例、信息节奏和叙事装饰。

## 一句话

**羊皮纸的底、金箔的骨、七元素的强调、卷轴式的留白**——把所有界面当成一页会被收进冒险家行囊的档案。

## 三个先决判断（不要跳过）

1. **模式**：`白昼 · 提瓦特`（纸/羊皮/暖白，适合档案、图鉴、角色、对话）还是 `夜幕 · 深渊`（靛蓝星海/深色金边，适合祈愿、大世界入口、活动页）？
2. **元素**：这一屏只准一个元素色（风/岩/雷/草/水/火/冰），贯穿徽记、进度、按钮、强调线；金与墨是中性色。
3. **原型**：从 `references/03-page-archetypes.md` 选一个骨架（大世界入口 / 角色档案 / 图鉴背包 / 任务对话 / 祈愿星海 / 地图地区 / 移动端 HUD），不要自创第八个。

写成一句话再动手，例如：
> 夜幕 · 深渊 + 岩元素 + 大世界入口；金边 HUD，羊皮纸内容区只出现一次。

## 八条 DNA

| # | 规则 | 落地做法 |
|---|---|---|
| 1 | **双材质** | 纸/羊皮（暖白、纤维、低对比）与星海（靛蓝、金箔、微光）必须有一处硬切换；同屏不要半纸半星海。 |
| 2 | **金线为骨** | 1px 金线 + 内层 1px 淡金线构成双层边；四角用角饰；分隔线用金色渐变而不是灰线。 |
| 3 | **一屏一元素** | 七个元素色只启用一个；其余用墨、纸、金。元素色只做徽记、进度、激活态、焦点，不做大面积背景。七元素总览/图鉴可并列展示七个元素作为数据，但页面主视觉仍只启用一个。 |
| 4 | **圆与拱** | 圆徽记、圆头像、圆小地图、胶囊按钮是游戏原样；拱形立绘框是网页叙事化处理，不是游戏原样，别把它当考据。不要 ZZZ 式 45° 切角和硬直角。 |
| 5 | **字有仪式，但别认错字体** | 游戏内 UI 与标题实际都以 HYWenHei-85W（黑体）为主；衬线/书法体只出现在 Logo、卡池 KV、活动主视觉。网页默认「粗黑标题 + 黑体 UI + 等宽数字」；要更强叙事感时，才在首屏加衬线展示字（Cinzel/思源宋体），并注明这是二创转译。不要 Impact、不要全站一种字。 |
| 6 | **留白即呼吸** | 面板内部至少 20–26px 内边距；标题与正文之间用金色细线分隔；信息密度低于 ZZZ，高于普通后台。 |
| 7 | **装饰有叙事** | 角饰、菱形、四芒星、元素徽记、命之座环、任务标点都必须指向一个信息（品质、元素、进度、地区），不做无意义花纹。 |
| 8 | **品质先于文字** | 3/4/5 星用边框、底色、光晕分层；用户先看见稀有度，再读名字。 |

## 材质的三层

1. **底**：暖白 `#FBF7EE` → 羊皮 `#ECE1CA` 的柔和渐变；叠极淡的纸纤维/噪点（opacity ≤ .16）。
2. **中**：面板用「纸面渐变 + 1px 金边 + 内层淡金线 + 四角角饰」；阴影大而软，像纸放在木桌上。
3. **顶**：元素辉光/金色高光只出现在徽记、按钮、稀有卡片上；面积不超过面板的 15%。

夜幕模式把「纸」换成「星海」：`#0B0E1A → #232A44` 的径向渐变，叠稀疏星点（1px 圆点，opacity ≤ .8），金线变亮金，文字变暖白。**不要把白昼面板直接反色**——纸的暖白和星海的冷蓝是两种材质，要分别给色。

## 气质参照

- **西风骑士团档案室**：木桌、羊皮纸、金线封皮、手写编号；适合角色/任务/图鉴。
- **星海祈愿台**：深蓝夜空、金色星轨、元素徽记缓慢旋转；适合祈愿/活动/首页 KV。
- **冒险家行囊**：布面、皮革、铜扣、手写标签；适合移动端 HUD、物品卡。
- **七天神像**：石台、金纹、元素光；适合章节封面、空状态、加载页。

## 什么不是原神味（反例）

- 紫蓝渐变 + 玻璃拟态 + 大圆角白卡：这是通用 SaaS，不是提瓦特。
- 直接贴游戏立绘/图标/Logo/KV：只学语言，不搬资产；素材版权不属于你。
- 七种元素色同时出现、每个按钮一个颜色：元素色是**强调**，不是调色盘。
- 金色边框 + 黑色背景但没有任何角饰/徽记/留白：只是「黑金风」，缺少叙事装饰。
- 用 ZZZ 的 45° 切角、Impact 巨字、荧光色：那是新艾利都，不是提瓦特。
- 全站衬线或全站黑体：标题与 UI 的字体分工是这套语言的核心；但也要知道游戏内其实以黑体为主，衬线是网页的叙事化加法，不是「官方原来如此」。
- 把「羊皮纸」做成纯米色平涂：没有纤维、没有层次、没有内层金线，像旧模板。

## 两个模式怎么选

| 内容 | 模式 | 元素 | 原型 |
|---|---|---|---|
| 角色介绍 / 图鉴 / 任务 / 档案 | 白昼 | 角色对应元素 | 角色档案 / 图鉴 / 对话 |
| 首页 KV / 活动 / 祈愿 / 版本页 | 夜幕 | 版本主元素 | 大世界入口 / 祈愿 |
| 地区介绍 / 地图 / 世界观 | 白昼或夜幕 | 地区主元素 | 地图地区 |
| 移动端 | 继承 | 继承 | 移动端 HUD |

## 交付前的「像不像」自检

1. 遮住文字，只看色块与线：能不能认出「纸 + 金线 + 一个元素色」？
2. 去掉所有装饰：信息层级还成立吗？（成立才叫装饰，不成立叫遮丑。）
3. 把元素色换成另一个：页面还稳吗？（稳，说明元素色只是强调；不稳，说明用多了。）
4. 把页面缩小到 390：金边、角饰、徽记还在，但没有横向滚动吗？
5. 关掉动画：圆扩散、卷轴展开、星辉都消失后，用户还能完成操作吗？

## 与 ZZZ / 其他风格的边界

- **ZZZ**：黑/纸硬对比、切角、Impact、荧光、市政编号；原神：暖纸/星海、圆拱、衬线、金箔、元素徽记。
- **星穹铁道**：更冷的银蓝、列车/太空、几何切面；原神更暖、更手作、更卷轴。
- **通用奇幻**：只有金色+棕色；原神必须有「七元素之一 + 金线 + 纸/星海材质 + 叙事装饰」四件套。
