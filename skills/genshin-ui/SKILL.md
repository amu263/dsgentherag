# 原神 UI 设计（genshin-ui）

把《原神》的界面语言变成可执行的设计决策。你不是在“贴金色边框”，而是在做一页**会被收进冒险家行囊的提瓦特档案**：暖纸/星海的双材质、金箔的双线、一个元素色的强调、圆徽记与拱形框，以及有叙事意义的纹样。

> 硬边界：**不下载游戏、不抓取游戏资源、不使用官方立绘/图标/Logo/KV/字体文件**。只学语言，不搬资产。字体只写回退名。

## 先做三个判断（不要跳过）

1. **模式**：`白昼 · 提瓦特`（羊皮纸/暖白，适合档案、图鉴、角色、对话）还是 `夜幕 · 深渊`（靛蓝星海/深色金边，适合祈愿、大世界入口、活动页）？
2. **元素**：这一屏只启用一个（风/岩/雷/草/水/火/冰），金与墨是中性色。元素色只做徽记、进度、激活态，面积 ≤ 15%。
3. **原型**：从 `references/03-page-archetypes.md` 选一个（大世界入口 / 角色档案 / 图鉴背包 / 任务对话 / 祈愿星海 / 地图地区 / 移动端），不要自创第八个。

写成一句话再动手，例如：
> 夜幕 + 岩元素 + 大世界入口；金边 HUD，羊皮纸内容区只出现一次。

## 八条 DNA（缺一条就不像）

| # | 规则 | 落地做法 |
|---|---|---|
| 1 | **双材质** | 暖白羊皮（纤维、低对比）与靛蓝星海（金箔、微光）必须有硬切换；同屏不混。 |
| 2 | **金线为骨** | 1px 金边 + 内层 1px 淡金线 + 四角角饰；分隔线金色渐变。 |
| 3 | **一屏一元素** | 只启用一个元素色；其余用墨/纸/金。 |
| 4 | **圆与拱** | 圆徽记、圆头像、圆小地图、拱形立绘框、胶囊按钮；不要 ZZZ 切角/硬直角。 |
| 5 | **字有仪式，但别认错字体** | 游戏内 UI 与标题实际都以 HYWenHei-85W（黑体）为主；衬线/书法体只出现在 Logo、卡池 KV 与活动主视觉。网页默认用「粗黑标题 + 黑体 UI + 等宽数字」，需要更强叙事感时才在首屏加衬线展示字（Cinzel/思源宋体），并说明这是二创转译。 |
| 6 | **留白即呼吸** | 面板内边距 20–26px；标题/正文用金线或 16–24px 空白分隔；密度低于 ZZZ。 |
| 7 | **装饰有叙事** | 角饰/菱形/四芒星/元素徽记/命之座环/任务标点都指向信息，不做无意义花纹。 |
| 8 | **品质先于文字** | 3/4/5 星用边框/底光/光晕分层，用户先看稀有度再读名字。 |

## 工作流

1. **定调**：完成三个判断；从 `references/01-design-dna.md` 找气质参照。
2. **取令牌**：复制 `assets/genshin-tokens.css`；只改元素/模式属性，不新增裸色值。
3. **搭骨架**：按 `references/03-page-archetypes.md` 的区块顺序；先占位再换内容。
4. **上组件**：金边面板、元素徽记、品质卡、胶囊 tab、HUD、小地图、任务追踪、对话框，从 `references/04-components.md` 取配方。
5. **加质感与动效**：`assets/textures/` + `references/05-motion.md`。先选网页工程层（元素涟漪 / 卷轴展开 / 星辉浮现 / 镜头推移），再按第二部分的九类游戏动效原型（菜单展开 / 祈愿开箱 / 星级揭晓 / 物品获得 / 对话 / 升级 / 元素反应 / 加载 / 环境粒子）补仪式感。
6. **写文案**：按 `references/06-copywriting.md`；**不要写说明性冗余文字**，标签优先于句子。
7. **自检**：跑 `node scripts/audit.mjs <你的.html>`，再对照交付清单。

## 快速配方

| 需求 | 直接这样做 |
|---|---|
| 大世界入口/首页 | 星海底 + 巨大元素徽记（opacity .07）+ 衬线标题 + 1 句 lead + 2 CTA；左小地图、右任务、底部 4 个 52px 动作圆钮 |
| 角色档案 | 左拱形立绘框（300–420px）+ 元素徽记 + 五星；右侧 4 格属性 + 3 行天赋 + 命之座环 |
| 图鉴/背包 | 左分类 180px + 胶囊 tab + 4 列品质卡（3 蓝/4 紫/5 金，图 1:1） |
| 任务/对话 | 88px 圆头像 + 纸框 + 说话人（衬线/元素色）+ 2–3 个菱形选项 |
| 祈愿 | 星海底 + 金色星轨 + 深墨金边按钮 + 结果卡星辉浮现 |
| 地图/地区 | 羊皮纸/星海画布 + 菱形路标 + 地区标签 + 地点列表 |
| 按钮 | 主：深墨底 + 金边 + 菱形前缀；次：透明 + 细金边；hover 上浮 1px |
| 面板 | 纸面渐变 + 1px 金边 + 内层淡金线 + 四角角饰 + 大软阴影 |
| 菜单展开 | 世界降饱和压暗 240ms；面板 360ms 上浮；列表 40–60ms 错峰，不整块弹入 |
| 祈愿开箱 | 星轨蓄力 800ms → 金/紫爆发 400ms → 卡面 520ms；五星总时长 2.6s，四星 1.8s，可跳过 |
| 拾取物品 | 左下卡片 320ms 滑入 + 稀有度光晕，停 2.4s 后 400ms 淡出，最多叠 3 张 |
| 对话 | 黑边 260ms 收拢；名字先出；打字机 28–35 字/秒，减少动效时整段显示 |

## 硬性禁止

- 下载游戏、抓取资源包、使用官方立绘/图标/Logo/KV/UI 截图。
- 内嵌/分发 HYWenHei、汉仪文黑等商业字体。
- 七种元素色同时出现；元素色大面积铺底。
- 紫蓝渐变 + 玻璃拟态 + 大圆角白卡（通用 SaaS 味）。
- ZZZ 式 45° 切角、Impact 巨字、荧光色（那是新艾利都）。
- 纯米色平涂当羊皮纸；没有纤维、没有内层金线、没有角饰。
- 主视觉堆说明文、卡片写教程、按钮写「了解更多」。
- 无限旋转装饰环（除加载/祈愿主徽记，且 ≥60s）、弹跳、回弹、超过 1s 的渐入。

## 交付前清单

- [ ] 只有一种元素色，且贯穿徽记/进度/激活/焦点
- [ ] 有金边双线 + 四角角饰（或等价金线结构）
- [ ] 标题与 UI 有字体分工（游戏内默认黑体；衬线仅作叙事转译），数字等宽；没有全站一种字
- [ ] 白昼有纸纤维/暖纸层，夜幕有星海/冷蓝层；不是纯平色
- [ ] 至少一处圆徽记/拱形/圆环；没有 ZZZ 切角
- [ ] 3/4/5 星品质有可见分层
- [ ] 主视觉没有说明性/冗余文字；按钮是具体动作
- [ ] 390px 无横向滚动；角饰/金边不被裁
- [ ] `prefers-reduced-motion` 下降级，功能仍完整
- [ ] `audit.mjs` 通过；没有外链图片/官方素材域名/裸色值
